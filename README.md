# Lathamix Specified Website

## Files
- index.html — website structure/content
- style.css — design and responsive layout
- script.js — menu, demo player and contact-form behavior

## Before publishing
1. Replace YOUR_EMAIL@example.com with your real email.
2. Replace YOUR_USERNAME in the social links.
3. Replace the sample project titles with your real releases.
4. Add your real streaming links.
5. Connect the contact form to a form service such as Formspree if you want messages delivered.

## Free hosting
GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository.
3. Upload these three files.
4. Open Settings → Pages.
5. Select Deploy from branch → main → /root.
6. Save. GitHub will provide your free website address.
